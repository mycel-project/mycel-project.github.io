To learn how to use Mycel in practice, refer to the [Mycelium manual](https://mycel-project.com/docs/mycelium/) or the documentation specific to your [implementation of Mycel](https://github.com/mycel-project/awesome-mycel).

- **[Implement Mycel](implement/index.md)** — integrate Mycel into your own tools
- **[Contribution Guide](contribute/index.md)** — improve Mycel's codebase, add features or fix things
- **[Glossary](reference/glossary.md)** — terminology reference
- **[API Reference](reference/api.md)** — REST API documentation
