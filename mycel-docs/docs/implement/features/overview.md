# Overview

This section describes high-level features and workflows that combine API communication and resources into learning functionality.

What's described here reflects how Mycel was designed to be used — but it's only one way to build on top of it. You're not required to follow these workflows, or even to use all of the primitives described here. You're free to design your own workflows directly from the underlying building blocks (resources, API endpoints, etc.), independently of what's covered in this section.

Feel free to suggest ideas, improvements, or entirely new workflows.
